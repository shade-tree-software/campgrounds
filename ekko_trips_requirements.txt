# What the WEB APP needs, and nothing else.
#
#     pip install -r ekko_trips_requirements.txt
#
# The offline batch tools (detect_people.py, process_memos.py) are NOT here —
# they live in tools_requirements.txt, which installs this file too. That split
# is not tidiness: "the web app never imports cv2 / faster_whisper" is a
# load-bearing invariant (those models cost 100 MB and several hundred MB
# resident, which a one-shot subprocess pays for seconds and a web worker would
# pay for its whole life). Keeping their dependencies out of this file is what
# makes the invariant checkable rather than merely stated, and keeps a host that
# only serves pages from carrying ~190 MB it will never load.
#
# Every line below is reachable from the app. Verified by walking the imports of
# ekko_trips_app.py / trips.py / weather_finder.py / ridb/ and resolving the
# dependency closure; pyOpenSSL and python-dotenv were listed here for a long
# time and are imported by nothing (Werkzeug's dev-cert path uses cryptography,
# and the one .env reader in the tree is hand-rolled in tests/ specifically to
# avoid the dependency).
