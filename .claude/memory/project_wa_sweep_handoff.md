**KEY WA RULES proven:**
1. **Federal dominates the mountains** — huge national-forest inventory: Gifford Pinchot, Mt Baker-Snoqualmie, Okanogan-Wenatchee (Naches/Cle Elum/Wenatchee River/Entiat/Chelan/Methow Valley/Tonasket districts), Olympic, Umatilla (Blue Mtns), Colville NFs. NPS: Olympic, Mt Rainier, North Cascades complex, **Lake Roosevelt NRA** (big — Spring Canyon/Keller Ferry/Fort Spokane/Porcupine Bay/Evans/Kettle Falls/Gifford/Hunters/Hawk Creek/Marcus Island/North Gorge/Snag Cove/Jones Bay/Kettle River). USACE: Snake River (Charbonneau/Fishhook/Windust/Little Goose Landing/Chief Timothy) + Columbia (Plymouth/Hood Park). **BLM = `park_type: dnr` in the RV Life data is WA DNR (state); real BLM is the Yakima River Canyon (Big Pines/Umtanum/Roza), Coffeepot Lake, Twin Lakes — verify operator.** NPS/USFS concessionaire-run campgrounds (Sol Duc Hot Springs, Keller Ferry) = federal.
2. **HUGE under-23-ft skip rate in the NFs** — many small GPNF/Olympic NF/Okanogan-Wenatchee sites cap at 16/18/20/21 ft. Rule: rec.gov max-vehicle ≤21 ft DISQUALIFIES unless firsthand reviews show 28-30+ ft rigs fitting (Seal Rock, Goodell Creek kept that way); 22 ft borderline keep. Also skipped many walk-in/boat-in (Stehekin, Ross Lake camps, Ozette, most Olympic coast), 4WD-only, closed-road (2026 flood/fire closures: Buck Creek, Troublesome Creek, San Juan, Iron Creek), and group-only camps.
3. **WA State Parks** reserve via **washington.goingtocamp.com** (Aspira SPA, no clean US-eDirect API — use parks.wa.gov page + bare goingtocamp URL). DNR camps = FCFS/Discover Pass (dnr.wa.gov), ownership `state`. WDFW water-access = `state`.
4. **Local is rich** — county/city/port-district parks PLUS **Public Utility District (PUD) parks** (Chelan/Grant/Douglas PUD: Beebe Bridge, Daroga[state-operated], Crescent Bar, Entiat area) and **Tacoma Power / Seattle City Light / PacifiCorp / PSE utility parks** (Alder Lake/Taidnapam/Mossyrock = Tacoma Power=local; Boundary Dam = Seattle City Light=local; Cresap Bay = PacifiCorp=private utility; Kulshan = PSE=private utility). WA PUDs & municipal utilities are local gov → `local`. Port districts (Wahkiakum/Skagit/Anacortes/Garfield/S.Whidbey) = local. **Fairgrounds:** keep only if year-round/seasonal public transient camping (most WA county fairgrounds run real RV parks — Grant/Kittitas/Spokane/Okanogan/Chelan Expo/Enumclaw kept); skip event-only (Puyallup/WA State Fair).
5. **Private skips were heavy** — WA has many membership (Thousand Trails ×5, K/M Resorts, Coast-to-Coast, Escapees/SKP, Airstream/nudist clubs), Elks/Moose/Eagles lodges, casino overnight lots (7 Cedars, Tulalip, Silver Reef, Nooksack, Swinomish[the CASINO lot — but the separate Swinomish RV Park is a real park], Quil Ceda, Little Creek, Lucky Eagle, Mistequa), adults-only/55+, residential/owned-lot, and permanently-closed parks. Tribal-operated real RV parks = `private` (Quileute Lonesome Creek, Skokomish Twin Totems, Angel of the Winds, Swinomish RV Park).
6. **Coastal:** Pacific coast (Long Beach Peninsula, Ocean Shores/Grays Harbor) has genuine dune fields + shore forest → `coastal dunes` (Grayland Beach, Pacific Beach, South Beach, plus legacy Kalaloch) / `coastal woods` (Cape Disappointment, Ocean City, Twin Harbors, Screamin' Eagle). Puget Sound / Hood Canal / Salish Sea = saltwater → `bayfront`/`bayview`. Columbia/Snake/reservoir parks measured to high-water edge (reservoir drawdown doesn't downgrade).
