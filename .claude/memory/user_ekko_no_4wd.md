EKKO does not qualify for roads or camping areas that require four-wheel drive (AWH 2026-09-29). Its AWD does not count, so a campground whose only access an agency says is "4WD only" or "4WD required" fails the access gate and is excluded, not added with a caveat. First case: RI East Beach (Ninigret), a barrier-beach over-sand RV campground.

**Why:** AWH ruled on it directly after the state-gap pass flagged East Beach as an open question.

**How to apply:** treat an agency-stated 4WD requirement like a stated size limit under 23 ft, see [[feedback_min_site_length]]. Weight limits are a separate rule, see [[user_ekko_weight]].
