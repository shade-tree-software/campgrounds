EKKO does not qualify for roads or camping areas that require four-wheel drive (AWH 2026-09-29). Its AWD does not count, so a campground whose only access an agency says is "4WD only" or "4WD required" fails the access gate and is excluded, not added with a caveat. First case: RI East Beach (Ninigret), a barrier-beach over-sand RV campground.

**Why:** AWH ruled on it directly after the state-gap pass flagged East Beach as an open question.

**How to apply:** treat an agency-stated 4WD requirement like a stated size limit under 23 ft, see [[feedback_min_site_length]]. Weight limits are a separate rule, see [[user_ekko_weight]].

**A 4WD RECOMMENDATION excludes too (AWH 2026-10-21).** DWR's Rapidan WMA page says the roads beyond the state-maintained part are "narrow ... can be rough. A four-wheel drive vehicle recommended"; asked whether a recommendation (not a requirement) counted, AWH said drop both sites (438 Taylor Mountain Rd, 440 Cobblestone Row; logged in audit/verify/criteria_drops.py). So an agency recommending 4WD for the access is a drop I may make and report.

**AWH's own road report outranks the agency's 4WD warning (AWH 2026-10-21).** AWH drove FR 85A to the three westernmost Flagpole sites (55, 402, 403) in 2WD and judged Long Run Road #4-#6 (56-58) 2WD-passable from Little Dry River Rd on a video. Those stay, each with a caution line in the note (road not always maintained or promptly repaired after storm washouts; may have deteriorated since). Sites AWH could not confirm went: Flagpole 404/405/406, Long Run #1-#3 + 521. So a 2WD confirmation from AWH keeps a site despite an agency 4WD recommendation; without one, the recommendation drops it.
