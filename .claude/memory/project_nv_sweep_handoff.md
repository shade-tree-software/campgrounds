**KEY NV RULES proven:**
1. **park_type `dnr` = BLM (federal) in NV, NOT a state DNR** — NV has no state DNR campgrounds; ~63% of the state is BLM. Verified per entry (Hickison, Sacramento Pass, Cleve Creek, Illipah, Red Rock Canyon, Meadow Valley, Wilson Canyon, Snowbird Mesa all confirmed BLM). A couple `dnr`/`national`/`commercial` tags reclassified to the real operator (Ward Charcoal Ovens → state; Timber Creek/White River/Angel Creek/Kyle Canyon → USFS not the tagged type).
2. **Federal DOMINATES (53/124):** BLM, USFS **Humboldt-Toiyabe NF** (largest NF in lower 48 — Ruby Mtns [Thomas Canyon, Angel Lake, Angel Creek], Mount Charleston/Spring Mtns [Kyle Canyon: Fletcher View/Hilltop; Lee Canyon: McWilliams/Dolomite], Ely RD [Ward Mtn, Berry Creek, Cave-area], Jarbidge, Santa Rosa), NPS **Great Basin NP** (Upper/Lower Lehman, Baker Creek, Wheeler Peak — Grey Cliffs is tent-only, skipped) + **Lake Mead NRA** (Boulder Beach, Callville Bay, Echo Bay, Government Wash), USFWS (Pahranagat, Sheldon, Ruby Lake/South Ruby). **HUGE under-23-ft skip rate** on high-elevation FS/NPS sites (Lye Creek, Cherry Creek, Berry Creek, many capped 16-22 ft).
3. **State parks = Nevada Division of State Parks**, reserve via **reservenevada.gov** (US eDirect portal, `#!park/<PlaceId>` deep links — same family as ReserveOhio/Florida). Some FCFS. Rye Patch & Lahontan sit on Reclamation dams but are state-park-operated → `state`. NDOW WMAs (Dave Deacon/Kirch) also = `state`.
4. **Local is thin (5):** Washoe County (Davis Creek), Douglas County (Topaz Lake), Clark County (Shooting Complex RV Park — verified public, not shooters-only), Churchill County (3C Event Complex fairgrounds — year-round public RV area, not event-only), Pioche City (free town RV park). Confirm gov operator; RV Life mis-tagged Pioche RV Park & Campground as `city` (it's private) and Clark County Shooting Complex as commercial (it's local).
5. **Private (44) needed the HARDEST vetting** — NV is full of snowbird/55+/long-term-residential resorts (Vegas valley, Pahrump, Laughlin, Mesquite, Reno) and casino overnight lots. Skipped: King's Row/Riviera/Pahrump Station/Cree (55+/residential/MHP), Pair-A-Dice/Boulder Oaks (Escapees co-op/long-term), F.O.E. Tribal camping (Pyramid Lake dry beach camping) = `private`.
6. **Landlocked — NO coastal designations.** Lake Tahoe is an inland lake, not Great Lakes/ocean, so `coastal woods` never applies (Nevada Beach, forest-screened & set back from the Tahoe beach with no sightline → not-waterfront). NV lakes lack genuine wind-dune fields so no `coastal dunes` either.
